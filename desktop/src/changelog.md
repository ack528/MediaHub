# 更新日志

> 每次发布时同步到 GitHub Release 的说明里;手机端「设置 → 关于 → 更新说明」和管理程序「关于 → 更新说明」会显示这里的内容(随程序打包)。
> 版本号分开计:手机端(LocalBrowse)和服务端 / 管理程序(MediaHub)各自一套,哪一端有改动才发哪一端。
> 写法约定:每个版本几条短句,纯文本(不用加粗、代码标记和嵌套列表),方便在手机和管理程序里直接显示。

## 手机端 LocalBrowse

### 4.1.0 · 2026-10-25
- 新增:群组与随机浏览支持图片、GIF、视频混合幻灯片播放，可选择图片停留时间、列表顺序、倒序或随机播放；视频从头播放并在播完后切换，支持暂停、继续、跳过及结束。
- 新增:设置中的服务器状态与配置页面，可查看运行时间、媒体与群组数量、扫描和优化任务状态。管理员可修改网络、媒体目录、缓存、视频转码、存储优化、后台调度、更新与日志参数，并远程重启或重新扫描。
- 保护:保存配置校验参数及文件版本，保留未编辑项和敏感凭据；后台暂停幻灯片，加载失败暂停等待操作。

### 4.0.2 · 2026-10-24
- 修复:服务器管理中的箭头固定在统一右边距,长名称单行省略,当前服务器标签不再挤偏箭头。
- 调整:已保存服务器的展开区沿用设置页卡片、文字、边距和分隔线,移除额外缩进;重命名改为同主题的内嵌输入框,增加取消重命名和取消删除。

### 4.0.1 · 2026-10-24
- 维护发布:同步最新更新说明,配合 MediaHub 3.3.3 的索引恢复、扫描与存储优化修复。手机端浏览和播放器行为保持一致。

### 4.0.0 · 2026-10-20
- 重构:整个应用按 Telegram 新版(2026)的样子重做。白天白色顶栏、夜间官方 Dark Blue;设置页是浅灰底 + 白色圆角卡片,首页每个分类配彩色图标,蓝色粗体小节标题、右侧蓝色当前值、新版开关。
- 新增:主界面底部悬浮的液态玻璃底栏,三个标签:文件夹 / 随机 / 设置(搜索在文件夹页右上角)。底栏是两头全圆的胶囊、居中,每个标签的大小按参考截图。在别的标签按返回回到文件夹。
- 新增:液态玻璃。所有页面的顶栏是半透明玻璃,列表一直铺到屏幕顶,滚动时内容从顶栏下面模糊地透出来;底栏带边缘折射和高光。Android 13 起完整效果,Android 12 只有模糊,更早的系统和低内存手机只画半透明底色。设置 → 外观 → 液态玻璃 可改成「只要毛玻璃」或关掉。
- 优化:登录页、搜索框、弹窗、下拉菜单的圆角和样式统一(搜索框是顶栏里的圆角胶囊,弹窗 22dp 圆角)。动画没有改。
- 新增:液态玻璃动效(移植自 Kyant 的 AndroidLiquidGlass 示例)。底栏的选中块在标签之间弹簧滑动,按住或拖动时变成一颗轻微折射的玻璃透镜,可以拖到别的标签松手切换,按压处有一团跟手的柔光;开关的滑块弹簧移动、途中被拉长。
- 调整:去掉主界面左上角的菜单键和侧边栏,里面的功能都在「设置」里(服务器管理、日志、关于、退出登录;「重新生成随机序列」移到 存储与缓存)。
- 重绘:应用图标(天蓝渐变 + 玻璃高光 + 叠放的照片和播放角标)和「随机浏览」的头像(紫色渐变圆 + 随机图标)。
- 调整:默认深色主题(原来没改过主题、用"跟随系统"的,升级后也换成深色,只换这一次)。浅色主题下消息页改成白色背景,顶栏和底栏改成浅灰玻璃、阴影更明显,和白色列表分得清。
- 调整:元素和字号按同一部手机上的 Telegram 截图逐像素对齐:大标题 20sp 粗体、顶栏 56dp,设置项正文 15sp、说明 12.5sp(比原版略小一号),单行 50dp、两行约 60dp,首页图标 28dp;底栏 56dp。界面字体跟随系统,行高统一为字号的 1.3 倍。
- 修复:列表铺在玻璃顶栏下面以后,打开图片时动画会从顶栏后面冒出来、盖住标题栏。现在被顶栏 / 底栏盖住的那截不算看得见的部分,动画从顶栏下沿开始展开。
- 调整:设置 → 服务器管理 点一台服务器直接在下面展开操作(切换、重命名、退出登录、删除),重命名和删除确认也在原地完成,不再弹出对话框。图片和视频查看器保持原来的样式(不加玻璃)。
- 新增:docs/17 是这次 UI 重构的方案和参考项目说明。
