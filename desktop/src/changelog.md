# 更新日志

> 每次发布时同步到 GitHub Release 的说明里;手机端「设置 → 关于 → 更新说明」和管理程序「关于 → 更新说明」会显示这里的内容(随程序打包)。
> 版本号分开计:手机端(LocalBrowse)和服务端 / 管理程序(MediaHub)各自一套。

## 手机端 LocalBrowse

### 2.6.0 · 2026-10-07
- 视频页:控制条显示时,在底部功能条(进度条下面那一排)左右滑动即可切换上一个 / 下一个媒体(滑动方向和设置里「右滑上一个」一致;横向滑动本来被快进快退占用,这里补上翻页的入口)。
- 点开媒体后左右滑动切换,退出全屏回到群组时,列表自动定位到退出时停留的那一项(不再停在打开时的位置);该项不在已加载的范围里时围绕它重新加载。

### 2.5.1 · 2026-10-07
- 检查更新更稳:GitHub API 被匿名限流(403)时,自动改用 releases/latest 跳转 + SHA256SUMS.txt 取最新版本,不再显示"检查失败"。
- 带 Lossless.dll 的版本第一次启动时把 DLL 保存到应用私有目录并一直保留;之后通过检查更新装上发布版(不含 DLL),DLL 仍在,可以重新提取着色器。

### 2.5.0 · 2026-10-07
- 新增**检查更新**:设置 → 关于 → 检查更新,查 GitHub Releases 上的最新版本,点「下载并安装」自动下载(校验 SHA-256)并调起系统安装器。
- 新增**更新说明**:设置 → 关于 → 更新说明,显示当前版本的更新内容和全部历史版本。
- 发布用的安装包不再内置 Lossless.dll(版权原因,不能公开分发);已经提取过着色器的手机更新后补帧照常可用。

### 2.4.0 · 2026-10-07
- 断网 / 网络切换不再"卡住":浏览接口和图片 / 视频各用独立的连接池与调度器;HTTP/2 每 10 秒保活,死连接几秒内发现并断开。
- 监听系统网络:断网时请求先等网络回来;Wi-Fi ↔ 移动数据切换时自动清理旧连接并重试。
- 接口请求(GET / PUT / DELETE)网络失败自动重试最多 3 次;DNS 失败时退回上次解析成功的地址。
- 播放器网络中断时重试约 40 秒,恢复后自动继续,不再几秒就弹"播放错误"。

### 2.3.0 · 2026-10-06
- 修复网格 ↔ 聊天流切换后位置丢失(回到最新)的 bug;网格里长按某一格,直接跳到聊天流里的这一条。

### 2.2.x · 2026-10-06
- 补帧(LSFG)着色器优先使用 FP16(Mali / 天玑 / 骁龙都快很多),失败自动退回 FP32;设置里可强制 FP32。
- 补帧自动降级新增:降低生成倍数(×4→×2)和输入分辨率两档;低功耗档从 50% 光流精度起步。
- 屏幕刷新率在 60 / 120Hz 之间切换时画面节拍不再顿挫;无补帧时按时间戳挑帧的节拍自动校准(60fps 视频不再发晃)。
- **非高通处理器直接禁用补帧**(天玑 / Mali 上性能跟不上)。
- 修复补帧降级日志里 `String.format` 把 `%` 当格式符导致的闪退。

### 2.1.x · 2026-10-06

## 服务端 / 管理程序 MediaHub

- 自动更新更稳:GitHub API 被匿名限流(403)时,自动改用 releases/latest 跳转 + SHA256SUMS.txt 检查新版本。

### 1.4.0 · 2026-10-07
- 新增**自动更新**:服务端每 10 分钟检查一次 GitHub Releases,发现新版本后自动下载、校验、安装并重启服务;新版本起不来会自动回退到旧版本。
- 管理程序「关于」页新增「软件更新」(当前 / 最新版本、检查更新、立即更新)和「更新说明」(当前版本更新内容 + 历史版本)。
- 打包只出便携版(不再生成安装包);发布一个体积小的 `MediaHub-<版本>-update.zip` 专供自动更新。

### 1.3.2 · 2026-10-07
- 浏览位置 / 播放进度写入改成后台写(先应答再写库),不再被扫描占着的写锁拖住几秒;数据库连接池 8 → 32。
- HTTP/2 保活 + 空闲连接回收,手机切换网络后服务端资源及时释放。

### 1.3.1 · 2026-10-07
- 修复管理程序「打开日志文件夹」点了没反应(改用自己的打开命令,失败会提示)。
- 各盘缓存占用列表顺序固定,不再上下乱跳。
- 扫描卡住修复:失败后状态改成「出错」并自动重试;数据库忙等待 10 → 60 秒;单个目录读取超过 90 秒自动跳过;超过 30 秒没进展时显示卡在哪个目录并可重新扫描。
