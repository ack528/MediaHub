## 0. 结论速览

| 结论 | 依据 |
|---|---|
| Jellyfin 的**视频**能力(按需 HLS 转码、硬件加速、字幕、trickplay)成熟,可直接复用 | Jellyfin / jellyfin-ffmpeg / Findroid |
| Jellyfin 的**照片**能力是短板:HEIC、AVIF、RAW 不被索引 | jellyfin#17312、论坛 AVIF 帖、heic-for-jelly 插件的存在 |
| Jellyfin 的 trickplay 在**只读/写满的媒体目录**上会反复失败(先编码、后写入)。你的 F:、G:、H: 基本没有剩余空间,必须踩这个坑 | jellyfin#18152 |
| "文件夹=群聊"的数据模型在 Jellyfin 里没有现成对应,需要自建一层(网关) | Photoview(目录=相册)、Stash、PhotoPrism 的做法 |
| 无限滚动时间线、日期跳转、占位图的最佳实践来自 Immich / Memories / Ente / Telegram | 见第 2 节 |
| Telegram 官方协议(MTProto)**不适合**用来驱动本地 NAS:Teamgram 社区版缺频道,基础设施很重,还要把 TB 级媒体导入 MinIO | Teamgram README |
| 播放器:Media3(ExoPlayer)为主,libmpv 作兜底,是 Jellyfin 社区已验证的组合(Findroid) | Findroid、libmpv-android |
| ffmpeg-kit 已退役,客户端**不要**依赖它 | ffmpeg-kit 仓库 / 检索结果 |

## 2. 按主题提炼的设计依据

### 2.1 "文件夹=群聊"的数据模型
- **Photoview** 把目录直接映射为相册,每个用户绑定文件系统路径,这是最接近目标的先例。
- **Stash / PhotoPrism** 都选择**原文件只读 + 生成物放独立目录**。你的 F:、G:、H: 几乎没有剩余空间,这条是硬约束。
- **Jellyfin** 的库模型围绕"媒体库"展开,文件夹只是浏览视图。这能凑合用(方案 A),但聚合统计(每个文件夹各类型的数量、最新一条)要 N+1 次请求。

### 2.2 滚动到哪加载到哪
- **Telegram API**:`getHistory` 用 `offset_id + add_offset + limit` 做**锚点式分页**,支持向前、向后以及围绕某条消息加载。我们的 `history` 接口沿用这个语义(游标 + `around`)。
- **Telegram 缩略图**:消息体里直接内联 stripped thumbnail(极小的 JPEG),下载大图期间先显示。对应我们的 **ThumbHash 内联**。
- **Immich / Memories**:服务端按月或日分桶,返回每个桶的条数,客户端据此建立滚动条与日期跳转,不需要加载全部条目。对应我们的 `buckets` 接口。
- **Paging 3**:`RemoteMediator` + Room 做本地缓存,占位项让滚动条长度稳定。

### 2.3 视频:直放、转封装、转码三档
- **Jellyfin**:客户端提交 DeviceProfile,服务端判定 DirectPlay、DirectStream 或 Transcode,并返回 HLS 地址;`MaxStreamingBitrate` 控制带宽。
- **go-vod / Memories**:不预转码,播放时按片段生成,片段缓存可淘汰。磁盘写满的环境只能这样做。
- **Findroid**:ExoPlayer 与 mpv 双后端可切换,是已验证的组合。
- **trickplay**:`/Videos/{id}/Trickplay/{width}/{index}.jpg` 提供进度条预览图。

### 2.4 图片格式覆盖
- Android 原生解码:JPEG、PNG、WebP、BMP;HEIF 需较新系统;**AVIF 需 Android 14+(Media3 文档)**。
- 想"尽量多格式",最稳的做法是**服务端统一转成 WebP/JPEG 再下发**。客户端只解两种格式,不依赖机型。
- 服务端回退链:`libvips`(含 libheif、libjxl、libraw)→ `ffmpeg` 取帧 → `ImageMagick` → ExifTool 提取内嵌预览 → 通用图标。

### 2.5 许可证注意
- 你只在自己的设备上用、不分发,GPL/AGPL 的"传染"义务基本不触发(义务发生在分发或对外提供网络服务时)。
- 如果将来要上架或分发 APK:不要拷贝 Findroid、Telegram 的代码;libmpv 与 FFmpeg 选 **LGPL 构建**;jellyfin-androidx-media 为 GPL-3.0,届时需替换。
- 方案 A 若使用 jellyfin-sdk-kotlin(LGPL-3.0),Android 上基本等同静态链接,需满足"允许用户替换库"的要求。想省事就自写 Retrofit 精简客户端。
