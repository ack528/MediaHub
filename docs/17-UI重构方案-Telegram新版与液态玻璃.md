# 17 · UI 重构方案:Telegram 新版风格 + 液态玻璃 + 通透

目标:手机端除播放器外的所有界面,改成 Telegram 当前版本(2026)的样子;顶栏、底栏、按钮、菜单这些"浮在内容上面"的部件用液态玻璃,内容从玻璃下面透出来。动画本轮不改。

## 二、"液态玻璃"和"通透"在本项目里指什么

- **液态玻璃**:浮在内容上面的部件(顶栏、悬浮底栏、悬浮按钮、菜单、搜索框、日期胶囊)采样它下面的内容,做 模糊 + 提高饱和度 + 边缘透镜折射 + 顶部一道细高光 + 柔和阴影,再盖一层很淡的白 / 黑膜。
- **通透(透视)**:列表、卡片一直铺到屏幕最顶和最底,顶栏和底栏是半透明的,滚动时内容在它们下面透出来,而不是被实色顶栏切掉。

> "透视"我理解为上面这种通透感。如果你指的是 3D 透视(比如卡片随手指倾斜),请告诉我,那属于动效,按你的要求放到下一轮。

## 三、按设备能力分三级

| 级别 | 条件 | 效果 |
| --- | --- | --- |
| 液态 | Android 13+(透镜折射要 RuntimeShader) | 模糊 + 饱和度 + 透镜 + 高光 + 阴影 |
| 毛玻璃 | Android 12 | 模糊 + 饱和度 + 高光,没有透镜 |
| 半透明 | Android 8–11,或低内存设备,或设置里关了 | 不采样,只画半透明的膜(和截图里一样的颜色,只是不模糊) |

设置 → 外观 新增「液态玻璃:开(默认)/ 只要毛玻璃 / 关」,关了就是第三级。

## 四、性能做法(参考 Square / Convx 的经验)

1. **只采样一次**:每个页面的内容记录成一个图层(`layerBackdrop`),所有玻璃部件共用它,不是每个部件各录一遍。
2. **滚动时冻结**:页面在快速滚动时,玻璃保持上一帧的采样,停下来再更新(滚动中的折射人眼看不清,每帧重录很费)。
3. **分辨率随模糊降低**:模糊越重,采样分辨率越低(最低 30%),模糊会盖住放大。
4. **大面积少用透镜**:顶栏是通栏的,只用模糊 + 饱和度;透镜和高光只给小部件(底栏、按钮、胶囊)。
5. **播放器和查看器不碰**:它们自己有黑底和动画,不叠玻璃。

## 五、分阶段

### 阶段 0:基础设施
- 依赖 `io.github.kyant0:backdrop:2.0.1`。
- 新建 `ui/glass/`:`GlassLevel`(三级判定)、`LocalGlassBackdrop`(当前页面的内容图层)、`Modifier.glass(shape, kind)`(顶栏 / 底栏 / 按钮 / 菜单几种预设)、`GlassFrozen`(滚动时冻结)。
- 设置项「液态玻璃」。

### 阶段 1:设计语言和设置页
- 配色换成新版:页面浅灰、卡片白、强调蓝;夜间同理。
- 组件:`TgCardSection`(白色圆角卡片)、`TgIconCell`(彩色方块图标 + 两行字)、新版开关、卡片内的小节标题和分隔线、右侧当前值。
- 顶栏:大标题、半透明玻璃、内容从下面滚过。
- 所有设置页按卡片重排;设置首页每个分类配彩色图标。

### 阶段 2:主界面加悬浮玻璃底栏(需要你拍板)
- 底栏四个标签:**文件夹 / 随机 / 搜索 / 设置**,和 Telegram 的 聊天 / 联系人 / 设置 / 个人资料 对应。侧边栏保留服务器切换和日志等少用入口。
- 架构变化:这四个页面要放进同一个页面(MainActivity 里切换标签),玻璃底栏才能采样到正在显示的列表。文件夹里的聊天页、设置的二级页仍然是独立页面,系统转场和预测性返回不变。
- 这会改掉"每个页面都是独立 Activity"这条以前定下的规矩(只改这四个入口)。**做之前请你确认。**

### 阶段 3:聊天页、搜索、随机
- 聊天页顶栏变成半透明玻璃,聊天背景和缩略图从下面透出来;"回到最新"按钮、日期胶囊、右上角菜单用玻璃。
- 文件夹内搜索的输入框做成玻璃胶囊。

### 阶段 4:登录页、弹窗、菜单
- 登录页:新版 Telegram 欢迎页的大图标 + 卡片式输入。
- 单选弹窗换成 Telegram 新版的圆角弹出列表;下拉菜单用玻璃。

### 阶段 5:性能检查和回退
- 在模拟器(Android 12 / 13+ / 8)上逐级看效果和帧率,低端机回退到半透明。

## 六、不做的

- 动画(页面转场、查看器展开、拖拽关闭):本轮不改。
- 播放器、查看器:不改。
- 缩略图、聊天气泡的内容样式:不改。

## 七、完成情况(手机端 4.0.0)

阶段 0–4 全部做完,另外按要求把查看器和播放器的界面也升级了:

| 部分 | 做法 | 位置 |
| --- | --- | --- |
| 玻璃基础 | `Modifier.glass`(三级)、`GlassHost`(采样图层)、设置项「液态玻璃」 | `ui/glass/Glass.kt` |
| 页面骨架 | `TgGlassScaffold`(玻璃顶栏 + 内容铺满)、`TgGlassPage`(设置页大标题)、`LocalBarInsets` / `barContentPadding`(列表让出顶栏和底栏) | `ui/tg/TgGlassBar.kt` |
| 卡片单元格 | `TgCardColumn` 自动把"小节标题到下一个小节标题"之间的行装进一张圆角卡片;`TgIconCell`、`TgTextCell`、`TgCheckCell`、新版 `TgSwitch` | `ui/tg/TgCells.kt` |
| 主界面底栏 | 四个标签共用一个页面(`MainTabs`),悬浮液态玻璃胶囊底栏;侧边栏打开时底栏隐藏 | `ui/MainTabs.kt` |
