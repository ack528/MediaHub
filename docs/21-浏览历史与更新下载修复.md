# 浏览历史、浏览模式与更新下载

版本：LocalBrowse 4.1.2 / MediaHub 3.4.2，2026-10-25。

## 浏览历史

群组右上角更多 → 浏览历史。可保存当前位置、选择记录恢复排序/筛选/视图/媒体锚点/偏移、删除单条或清空当前群组记录。文件已被移动或删除时提示失败，保留记录供用户删除，不静默跳到其他文件。原有“记住浏览位置”控制自动记录；手动保存仍可使用。

远端历史按账号及群组隔离，手机本地媒体模式使用按服务器命名空间隔离的本地记录。远端接口不支持或连接失败时显示错误，可刷新重试，不把失败展示成空历史。

配置位于管理程序“媒体库 → 浏览历史”，以及手机“设置 → 服务器状态与配置 → 浏览历史”。保存后按已有配置流程重启服务生效：

| 参数 | 默认值 | 范围/作用 |
| --- | --- | --- |
| browseHistory.enabled | true | 关闭后停止新增，已有记录仍可查询、删除 |
| browseHistory.intervalSeconds | 60 | 10–86400 秒；自动记录同时要求媒体位置变化 |
| browseHistory.maxEntries | 100 | 每账号每群 1–1000 条 |
| browseHistory.retentionDays | 90 | 1–3650 天；过期项不展示，写入时清理 |

GET/POST/DELETE `/api/v1/dialogs/{id}/browse-history` 分别读取、手动保存、删除记录；DELETE 的 `at` 参数选择单条，省略表示当前群组全部。最新恢复位置 PUT 仍兼容旧客户端，同时按配置生成历史检查点。SQLite v13 增加独立历史表，保留原有恢复位置与播放进度。

## 浏览顺序和位置

聊天流、网格、瀑布流全部从上向下使用同一排序方向，不再单独反转聊天数据或列表。切换模式复用同一 Pager 和数据，不触发网络重新取页；先记录媒体锚点，再恢复目标布局，忽略正在退出的布局所上报的位置。网格中目标项所在行的首项可能不同，未发生滚动时继续保留所选目标项，避免连续切换逐次漂移。

## 更新与幻灯片

取消多连接抢写同一分段，下载使用单写入者和 HTTP Range 续传；服务器忽略 Range 时从头覆盖，416 时重置无效断点。安装包需完整 SHA-256 校验后才从 `.part` 改为正式 APK。下载任务独立于设置页生命周期，禁止重复启动，源切换时进度不回退，校验前最多显示 99%。

正式 APK 与校验值保存于应用 files/updates，取消安装、安装失败、返回设置页及再次启动均可重复安装。清理只依据系统实际安装版本进行，启动安装器不算安装成功。更新元数据直接返回服务器缓存，GitHub 检查后台执行；下载复用接口连接、认证与固定证书校验，避免被媒体请求占用调度队列。服务器准备缓存新版本时清空旧包的校验值、大小和路径；手机兼容旧服务器，不采信未就绪缓存携带的旧校验值或大小，下载前重新确认已就绪版本。

幻灯片停留时间改为 0.5–10 秒滑动选择。图片计时与顶部浅灰细进度条使用同一动画比例，暂停、菜单及触摸不会重置已消耗时间；视频比例读取播放器进度。进度条在无信息的沉浸状态显示，从右向左缩短，播放时隐藏图片底部元信息。

## 验证范围

Android 单元测试覆盖真实 HTTP 续传、忽略 Range、损坏校验、APK 保留及实际版本清理，以及旧整数停留时间兼容。服务器测试使用实际 SQLite 与 HTTP 接口，验证历史排序、限制、去重、过期清理、账号隔离、关闭策略、保存与删除。发布另执行项目既有检查、签名证书与附件摘要验证。

本次未使用桌面自动化；未将单元测试等同于 Android 真机的安装器及手势验证。

## LocalBrowse 4.1.3 补充

设置 → 图片查看器 → 幻灯片进度条：粗细 0.5–12 dp（步进 0.5 dp），颜色可选预设或输入 6 位 RGB 色值，支持预览及恢复浅灰色 4 dp。设置保存在手机端，图片和视频播放共用，保存后立即生效；旧设置文件默认保持原有样式。

返回位置由播放队列保存。群组内随机队列固定返回本次起播的媒体，分页、暂停、播放结束及停止不丢失起播锚点；重新启动随机播放会记录新起点。顺序和倒序队列跟随当前媒体，随机切换至顺序或倒序后也按当前媒体定位。随机浏览标签及全局搜索沿用各自原有返回规则。只在队列成功创建后切换规则，失败或取消准备不改写原队列。

## LocalBrowse 4.1.4 补充

首页群组第二行默认显示当前服务器下该群组最新保存的浏览位置文件名，没有记录时显示“暂无浏览记录”。订阅本地浏览记录变更，返回首页自动刷新，沿用服务器命名空间隔离；所有群组共用一次 DataStore 订阅，不为每个群单独读盘或增加网络请求。设置中的“第二行内容”同步改名为“最近浏览的文件名”，保留原路径与隐藏选项。浏览位置保存及跨设备同步策略沿用既有设置。

设置 → 图片查看器 → 幻灯片全屏提示增加“图片全屏提示”：进度条、暂停按钮和倒计时、不显示。仅在图片信息隐藏的沉浸状态生效；倒计时显示在左下角暂停/继续按钮右侧，使用小号数字保留一位小数，与切图共用剩余比例，暂停或操作菜单时不会继续减少。视频继续使用进度条。

进度条位置可选上、下、左、右，图片和视频共用。横条从右向左缩短，竖条从下向上缩短；粗细与颜色仍可自定义。预览与播放器共用边缘绘制组件，进度条无触摸区域，不遮挡图片手势或视频操作。恢复默认同时还原为图片显示顶部浅灰 4 dp 进度条。旧设置文件继续使用顶部进度条。

视频画质修复：相邻页提前组合时不能固定读取旧的用户偏好，成为当前页时按最新设置初始化画质和编码。已手动选定的转码档位不再因原片码率低而自动改成原画，网络自动降档也不覆盖手动选择；服务端确有较低码率上限时仍遵守上限。点选已经在播放的自动档位也视为手动选择并保存，只改编码时不把临时自动档位写回首选。服务器偏好同步完成后重新读取本机时间戳并确认服务器未切换，避免覆盖等待网络期间的新选择。
