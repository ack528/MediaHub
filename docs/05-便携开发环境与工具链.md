> 目标:**所有编译工具和测试软件都在项目文件夹里**,删掉项目文件夹就等于卸载干净;不污染系统,不依赖 Android Studio。
> 状态:工具链已按本文档安装(2026-10-05),版本与 SHA-256 见 `tools\versions.json`。

## 2. `env.ps1`(已实现)

```powershell
. .\env.ps1        # 在项目根目录运行,前面的点不能少
```
- `JAVA_HOME`、`ANDROID_HOME` / `ANDROID_SDK_ROOT`、`ANDROID_USER_HOME`、`ANDROID_AVD_HOME`、`GRADLE_USER_HOME` → `tools\…`
- `GOROOT`、`GOPATH`、`GOCACHE`、`GOMODCACHE` → `tools\…`;`GOTELEMETRY=off`;`CGO_ENABLED=0`(纯 Go,无需 C 编译器)
- `TEMP` / `TMP` → `tools\tmp`
- `PATH` 追加 jdk、go、sdkmanager、adb、ffmpeg、exiftool、vips、sqlite3
- 不修改系统环境变量,不写注册表。

## 4. 无法完全"便携"的部分

| 项 | 说明 |
|---|---|
| Intel 核显驱动 | QSV 依赖 Windows 上的 Intel 图形驱动。**NAS 上必须单独验证**:`ffmpeg -init_hw_device qsv=hw -f lavfi -i testsrc -frames 1 -f null -` |
| adb | 手机开启开发者选项 + USB 调试(或无线调试),`adb devices` 确认 |
| 防火墙规则 | 放行 MediaHub 端口(仅专用网络),需要管理员权限一次 |
| 开机自启 | 任务计划程序条目放系统里,脚本提供安装与卸载 |
| `~\.android\adbkey` | adb 的授权密钥在 9 月已存在于用户目录,不属于本项目 |
