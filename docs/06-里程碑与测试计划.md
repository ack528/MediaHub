## M1 · 服务端 MVP(约 3 周)—— 进行中,核心已完成,见 00 号文档 §6
- 索引器(阶段 1 文件系统级 + 阶段 2 元数据)、稳定 ID、排除规则。
- 登录/令牌、`/server/info`、`/dialogs`、`/history`(含游标、around)、`/buckets`、`/search`。
- `/media/{id}/file`(Range)、`/poster`(ffmpeg 抽帧 + 每盘缓存 + 配额 + 自检回退)。
- `mediahub user add`、`start-all.ps1`。
- **验收**:用 curl 能遍历对话、翻页、取原图、取封面;重命名文件夹后 ID 不变;缓存不会写出配额。

## M2 · Android MVP(约 4 周)—— 主体已完成并在模拟器验证,收尾项见 00 号文档
- 服务器页 + 登录页;对话列表(标签/置顶);聊天流 + 网格 + 共享媒体标签。
- 原图加载 + 降采样 + 本地缩略图缓存 + 滚动策略;视频封面;查看器(缩放)。
- 视频**直放**(ExoPlayer)。阅读位置记忆。
- **验收**:在你的手机上浏览真实文件夹;网格滚动流畅;视频点开可直放。

## M3 · 视频转码(约 3 周)
- 播放决策器(direct/remux/transcode)、caps 上报。
- Jellyfin 桥接 + 反向代理 + 会话管理 + QSV 配置 + 软编兜底。
- 清晰度菜单、字幕、多音轨;失败回退到 mpv;外部播放器兜底。
- **验收**:mkv/avi/DTS/HEVC 10bit/AV1 样本都有明确结果(能播,或给出清晰提示);转码并发 2 路稳定;结束播放后 ffmpeg 进程被回收。

## M4 · 格式与功能补全(约 2.5 周)
- `render` 兜底(RAW 内嵌预览、HEIC/TIFF/JXL 等);GIF 处理。
- 排序维度(时间/名称/大小/类型)、自然排序、日期跳转 + 快速滚动条、全局搜索、音频/文件标签。
- 可选:sprite 进度条预览、`thumbMode=exif`、画中画。

## M5 · 稳定与收尾(约 1.5 周)
- 增量监听 + 每日校对;断网重试;异常文件;日志与 `/admin/status`。
- 任务计划程序自启;备份脚本;使用说明。
- 长时间(24 小时)运行与大对话(≥10 万条)压测。
