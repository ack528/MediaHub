# 08 · Android 界面还原 Telegram

> 要求:一个文件夹 = 一个群组;点开群组是**无文字消息**的聊天界面(只有图片/视频气泡);**聊天界面右上角**一键切换为网格显示媒体;整体 UI 与 Telegram 安卓版尽量一致。

## 1. 开源 Telegram 安卓版调研

| 项目 | 许可 | 说明 | 本项目的用法 |
|---|---|---|---|
| [DrKLO/Telegram](https://github.com/DrKLO/Telegram) | GPLv2 | 官方安卓源码,自绘 View 体系(`DialogCell`、`ChatMessageCell`、`SharedMediaLayout`…) | **界面度量的权威参照**。直接读源码取得尺寸/字号,不拷代码 |
| [Telegram-FOSS](https://github.com/Telegram-FOSS-Team/Telegram-FOSS) | GPL-2.0 | 去掉 Google 专有组件的官方分支 | 同上 |
| [Telegram X](https://github.com/TGX-Android/Telegram-X) | GPLv3 | 基于 TDLib 的第二客户端 | 参考,不采用 |
| [BirGram](https://github.com/GazizVR/BirGram) | 见仓库 | Kotlin + Compose + TDLib 的第三方客户端 | Compose 复刻聊天列表/聊天页的参考 |
| [Monogram](https://github.com/monogram-android/monogram) | 见仓库 | Compose + Material 3,自研 Rust MTProto | 参考 |
| [compose-telegram-clone](https://github.com/farhanroy/compose-telegram-clone) | 见仓库 | 纯 Compose 的 Telegram UI 克隆 | 参考 |

**结论**:不 fork Telegram(它的界面层与 MTProto 网络层紧耦合,见方案 D 的分析),而是**以官方源码为尺寸依据,用 Jetpack Compose 复刻**视觉与交互;数据层完全是自己的 REST 接口。

## 2. 对应关系

| Telegram | 本应用 |
|---|---|
| 聊天分组标签(顶栏下) | 盘符(全部 / D: / E: …) |
| 群聊 | 文件夹 |
| 群头像 | 该文件夹最新媒体的圆形缩略图;没有可显示图片时用 Telegram 的彩色底 + 首字母 |
| 最后一条消息 | `照片 / 视频` + 文件名(类型词用 Telegram 的"附件"蓝色) |
| 静音群的灰色计数 | 灰色圆角数量(该文件夹的媒体数) |
| 无文字的图片/视频消息 | 圆角媒体气泡;视频有居中播放键、左上角时长;右下角时间胶囊 |
| 日期服务消息 | 居中的半透明日期胶囊("今天 / 昨天 / 10月5日 / 2021年4月15日") |
| 共享媒体网格 | 右上角图标一键切换的 3–5 列网格,1dp 间隔 |
| 文档消息 | 不可预览的格式(RAW / JXL 等)显示为文件气泡:圆形图标 + 文件名 + 大小 |

## 3. 尺寸与配色

**取自官方源码(已核对)**:聊天列表行高 70dp(三行布局 76dp)、头像直径 52dp(半径 26dp)、头像起点 ≈11dp、文字起点 72dp、标题 17sp、消息 16sp、分隔线 1px。

**近似值(官方大文件无法完整取到,需在真机上微调)**:

| 项 | 取值 |
|---|---|
| 顶栏 | 白天 `#527DA3`(Telegram 经典蓝),夜间 `#212D3B`;标题 17sp 中等粗细,副标题 13sp |
| 列表背景 / 分隔线 / 名称 / 消息 / 时间 | `#FFFFFF` / `#DBDBDB` / `#222222` / `#8A8A8A` / `#999999` |
| 计数徽标 | 静音灰 `#C6C9CC`(未读用绿 `#4EC95E`,尚未启用) |
| 聊天背景 | 淡绿渐变 `#D8DDB0 → #8AB488`(模拟默认壁纸),夜间 `#0E1621 → #0B121A` |
| 媒体气泡 | 圆角 17dp,左下角 5dp(气泡尾巴);最大宽度 = 屏宽 72%,最大高度 = 屏宽 95%;按服务端给的宽高比占位 |
| 时间/时长/日期胶囊 | 半透明黑 `#66000000`,白字 12–14sp |

## 4. 聊天页行为
- **最新在最底部**,向上滑加载更早的内容(`LazyColumn(reverseLayout=true)` + Paging 3,每页 60,预取 30)。
- **只加载可见的**:离开屏幕的请求自动取消;滑动过快时(> 12 条/秒)暂停网络请求,减速后补载。
- **排序**(⋮ 菜单):按时间 / 名称(自然排序,2 < 10)/ 大小 / 类型;顺序可反转;类型过滤(图片 / 视频 / GIF)。聊天流默认"旧 → 新(最新在底部)",网格默认"新 → 旧"。
- **右上角图标**:聊天视图显示网格图标,网格视图显示聊天气泡图标,点击切换。
- 点击媒体进入查看器:左右滑动、图片缩放、视频播放(硬解失败自动改软解)。

## 5. 与 Telegram 仍有差距(已知)
- 没有发送栏(只读),没有侧边抽屉、搜索、已读回执。
- 气泡尾巴只是改了一个圆角,没有绘制真正的尾巴形状。
- 同一天内相邻气泡没有合并圆角(Telegram 会让同组消息相连)。
- 网格没有"按月分组"的标题行;"共享媒体"的图片/视频/文件分页标签尚未做。
- 字体用系统默认(Telegram 用 Roboto),中文字重对比略有不同。
